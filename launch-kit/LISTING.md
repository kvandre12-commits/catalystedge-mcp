## Full description

CatalystEdge is an explainable event-volatility and level-behavior companion. It helps
an AI assistant identify preparation, pre-event, active, and post-event windows around
scheduled catalysts, then assess user-supplied OHLCV bars around levels that matter.

A single wick is not called a breakout. CatalystEdge distinguishes testing,
provisional closes, rejection, accepted-but-unconfirmed trade, and confirmation backed
by a held retest, expanding volume, or decisive displacement.

The product includes no market-data feed, broker, order entry, API credential, or
SharpEdge dependency. Its separately installed open-source MCP server runs locally over
stdio and performs no network requests. Bundled event coverage is deliberately curated,
not advertised as a complete economic calendar.

CatalystEdge does not predict direction or recommend an options contract. Its options
checklist identifies missing evidence such as implied move, volatility comparison,
liquidity, expiration alignment, and maximum loss. Trade permission always remains
false.
