# CatalystEdge v0.1.0

CatalystEdge is an explainable catalyst-readiness and level-behavior MCP server.

Version 0.1.0 launches with five tools:

- `upcoming_events`
- `event_readiness`
- `assess_event`
- `assess_level`
- `options_readiness`

The release is keyless and network-free. It bundles a deliberately narrow event
catalog for the October 28, 2026 FOMC meeting and November 3–4 U.S. midterm election
results window. Custom CPI, earnings, and other events are supported but explicitly
remain unverified user input.

No tool predicts direction, recommends a contract, connects to a broker, or grants
trade permission.
